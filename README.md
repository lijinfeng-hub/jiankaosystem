# 智能排监考管理系统（Qt Widgets / C++）

“智能排监考管理系统”是一款面向学校教务与考试组织工作的桌面应用软件，提供教师、考试场次、考场资源和监考方案的统一管理，并根据教师职称、不可监考时段、时间冲突和监考工作量等条件自动生成排班方案。

## 软件信息

- 软件名称：智能排监考管理系统
- 软件版本：V1.0
- 软件形态：Windows 桌面应用程序
- 技术栈：C++17、Qt Widgets/Core/Gui、CMake
- 数据方式：本地 JSON 文件；排班结果支持 CSV 导出
- 默认登录：首次启动自动创建 `admin` 用户，初始密码为 `admin`，请仅用于开发、演示或测试环境

## 主要功能

- 用户登录与管理员权限识别
- 教师信息管理：工号、姓名、职称、授课课程和不可监考时段
- 考试场次管理：日期、时间段、教室、教室类型、课程、任课教师和监考人数
- 自动排班：任课教师硬约束、时间可用性、教授限制、负荷评分和工作量平衡
- 方案管理：保存、应用、更新备注、删除排班方案
- 教师维度查询与监考表 CSV 导出
- 操作审计日志：记录操作时间、操作人员、动作和详情

## 开发环境

- Qt 6（推荐 Qt 6.8；代码保留 Qt 5 兼容分支）
- CMake 3.16+
- 支持 C++17 的编译器

## 构建运行

建议使用 Qt Creator 打开本目录的 `CMakeLists.txt`，选择 Qt 6 Kit 后直接配置、编译和运行。也可以使用命令行：

```text
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

如果 CMake 报错 `Failed to find required Qt component Widgets`，说明当前 Qt 安装缺少 Qt Widgets 开发组件，请安装完整的 Qt Base/Widgets 开发包或切换到可用的 Qt Kit。

## 数据与日志

首次运行后，程序会在当前工作目录创建以下文件：

- `data/users.json`：用户账号及密码哈希
- `data/teachers.json`：教师基础信息、忙碌时段和运行时统计
- `data/exams.json`：考试场次和已应用的监考安排
- `data/schedules.json`：历史排班方案
- `logs/operations.log`：增删改、排班和方案操作日志

数据文件采用 JSON 文本格式，写入使用临时文件提交方式，能够降低程序中断时产生半文件的风险。请在正式使用前备份 `data` 和 `logs` 目录。

## 排班提示

如果排班失败或生成方案为 0 种，通常表示当前约束下没有足够的可用教师。可以检查教师数量、教授与非教授配置、不可监考时段、考试时间冲突、每场监考人数和教室设置，再重新生成方案。
